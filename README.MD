# Expense Tracker (Python CLI)

A simple command-line application to track daily expenses.

## Features
- Add, view and delete expenses
- Category-wise summary
- Input validation and exception handling
- Data saved in a local JSON file

## Project Structure
- main.py - menu and app logic
- validators.py - input validation
- storage.py - saving and loading data

## How to Run
Requires Python 3.8+. No external libraries needed.


python main.py


## Example

=== Expense Tracker ===
1. Add expense
2. View expenses
3. Delete expense
4. Summary
5. Exit
